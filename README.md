# final_worker — outcome-focused UI
No Docker. Windows + VS Code + local MySQL.

For `Check low stock items`, the Result explicitly says the count AND item names, e.g. `6 low-stock item(s): Wireless Headphones, ...` and a table below shows SKU, item, stock, reorder point, reorder quantity, and vendor.

Other tasks follow the same pattern: direct outcome first, then action, evidence, and a relevant table.
Refund decisions show APPROVED/PENDING/REJECTED with reasons.
